# Chair & Sofa Home Service Website

A professional, responsive website for a chair and sofa home service business. Built with modern HTML5, CSS3, and JavaScript.

## Features

- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices
- **Modern UI/UX**: Clean, professional design with smooth animations
- **WhatsApp Integration**: Direct contact via WhatsApp for instant communication
- **Contact Form**: Easy-to-use contact form with service selection
- **SEO Optimized**: Meta tags and structured content for better search visibility
- **Fast Loading**: Optimized code and assets for quick page loads
- **Accessibility**: Built with accessibility best practices

## Services Highlighted

1. **Deep Cleaning**: Professional sofa and chair cleaning with eco-friendly products
2. **Repair Services**: Expert furniture repair including springs, frames, and cushions
3. **Upholstery**: Complete reupholstery services with premium fabrics

## Pages Structure

- **Home Page**: Hero section, services overview, testimonials, and call-to-action
- **About Section**: Company story, mission, values, and why choose us
- **Contact Section**: Contact form, business information, and service areas

## Setup Instructions

1. **Download/Clone** the project files
2. **Replace placeholder images** in the `images/` folder with actual photos:
   - `hero-sofa.jpg` - Main hero image showing furniture cleaning
   - `about-team.jpg` - Team photo or service in action
3. **Update contact information**:
   - Phone numbers in HTML and JavaScript files
   - Email addresses
   - Service areas
   - WhatsApp number
4. **Customize content** as needed for your specific business
5. **Test on different devices** to ensure responsiveness

## Customization Guide

### Colors
The website uses a green color scheme that can be easily customized:
- Primary Green: `#2E8B57`
- Secondary Green: `#3CB371`
- WhatsApp Green: `#25D366`

### Fonts
- Primary Font: Inter (Google Fonts)
- Fallback: sans-serif

### Images Needed
1. **Hero Image** (hero-sofa.jpg): 
   - High-quality image of furniture cleaning in progress
   - Recommended size: 800x600px
   - Format: JPG/PNG

2. **About Team Image** (about-team.jpg):
   - Professional team photo or service demonstration
   - Recommended size: 600x400px
   - Format: JPG/PNG
